# iOS 12 compatibility port

- Lowered the package and deployment baseline to iOS 12.0.
- Added runtime shims for modern UIKit/Core Animation properties, semantic colors, SF Symbols, target-action controls and menu presentation.
- Added a UIKit blur fallback for the primary backdrop renderer and the supported auxiliary vibrance/blur surfaces.
- Disabled the unverified private QuartzCore/Metal Backboardd renderer on iOS 12 instead of using later-OS offsets or render ABIs.
- Gated platform-only App Library, WidgetKit and iOS 13 context-menu hooks.
- Replaced the iOS 14 document-picker API in Preferences with the iOS 12 UTI-based picker.
- Added separate build configuration for arm64 and the legacy arm64e toolchain profile.

This is source-level porting work. A Theos build and device runtime test are still required before calling the port stable.
